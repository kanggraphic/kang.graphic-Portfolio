# Wanted Sans Font Files

Place the following Wanted Sans font files in this directory:

- WantedSans-Regular.woff2
- WantedSans-Medium.woff2
- WantedSans-SemiBold.woff2
- WantedSans-Bold.woff2

Download from: https://github.com/wanteddev/wanted-sans

Until the fonts are added, the system will fallback to system-ui fonts.
